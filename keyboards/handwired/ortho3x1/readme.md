# ortho3x1 handwired

Custom handwired ortho3x1 keyboard.

Keyboard Maintainer: [nemalex](https://github.com/nemalex)
Hardware Supported: Custom handwired 3x1 ortho keyboard
Hardware Availability:

Make example for this keyboard (after setting up your build environment):

    make handwired/ortho3x1:default
